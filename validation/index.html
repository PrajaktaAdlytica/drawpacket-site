03Validation plan

Compare the same kind of work.

Document exclusions and changes in volume. Do not attribute every difference to the prototype.

01

Baseline

Record pay-app volume, review effort, return causes and material holds using the GC’s definitions.

02

Shadow

Manually classify a permissioned sample with the accountant.

03

Supervise

Test one selected module; a reviewer accepts or disputes each finding.

04

Reconcile

Compare true returns, false flags, omissions, time and follow-up burden.

05

Decide

Record the paid-pilot commitment or the reason to stop.

04Validation plan

Go / stop.

A polished interface is never the build decision.

01

Go only when

Fewer true returns without wrongful holds; approved state-specific templates; funded project owner.

02

Stop when

Waiver complexity, incumbent coverage or participation friction erases the gain.

03

Investigate before expanding

Material omissions, insurer/lender acceptance and cross-project data silos.
